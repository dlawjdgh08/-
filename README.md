# -
시각장애인은 버스가 정류장에 도착해도 버스 번호를 직접 확인하기 어렵기 때문에 원하는 노선을 놓치는 경우가 자주 발생합니다. 이 프로젝트는 이러한 불편을 해결하기 위해 인공지능 카메라 센서(AI Vision)​를 활용하여 버스 전면의 번호를 자동으로 인식하고, 그 결과를 음성(TTS)​으로 안내하는 시스템을 구현한 시뮬레이션입니다.

본 프로젝트는 Three.js를 이용하여 버스 정류장 환경을 3D로 구현하였으며, 버스가 인식 구간에 진입하면 AI 카메라가 버스 번호를 읽고 화면에 표시하는 동시에 음성으로 "버스 번호 ○○번입니다."라고 안내하도록 구성하였습니다.

주요 기능
버스가 정류장으로 이동하는 3D 시뮬레이션
AI 카메라를 이용한 버스 번호 인식 시뮬레이션
인식된 버스 번호를 화면에 실시간 표시 
Web Speech API를 활용한 음성 안내(TTS) 
시각장애인을 고려한 직관적인 안내 인터페이스 개발 목적

개발목적
이 프로젝트의 목적은 단순한 3D 그래픽 구현이 아니라, 인공지능과 음성 안내 기술을 활용하여 시각장애인의 대중교통 이용 편의성을 높이는 것입니다. 실제 환경에서는 AI 비전 모델(OCR, 객체 인식 등)과 카메라를 연동하여 버스 번호를 인식하고, 스마트폰이나 웨어러블 기기를 통해 음성으로 안내하는 시스템으로 확장할 수 있습니다.

기대 효과
시각장애인의 버스 이용 편의성 향상
버스 번호 확인 과정의 접근성 개선
AI 기반 스마트 교통 서비스 적용 가능성 제시
교통약자를 위한 보조 기술 연구 및 교육용 시뮬레이션 활용
